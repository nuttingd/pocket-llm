# Spec Compliance Matrix

This directory maps feature specifications to the North Star and Capability Ladder.

---

## Purpose

Track how each specification aligns with:
- **North Star Principles** - Does it uphold our non-negotiables?
- **Capability Ladder Milestone** - Which phase does this serve?

---

## Documents

| Document | Status |
|----------|--------|
| `01-v1-mapping.md` | Current V1 features mapped |

---

## Mapping Format

```
┌────────────────────────────────────────────────────────────┐
│ Feature: Context Compaction                                 │
├────────────────────────────────────────────────────────────┤
│ North Star Alignment: ✅ Local-first, Resource-respectful  │
│ Capability Ladder: M0 (Baseline)                           │
│ Status: Complete                                           │
└────────────────────────────────────────────────────────────┘
```

---

## Usage

When reviewing specs:

1. **Check alignment** - Does feature uphold North Star?
2. **Identify milestone** - Which phase does it belong to?
3. **Verify quality gates** - Does it meet acceptance criteria?
